Deep Cut is a surreal, emotionally charged multiplayer party game powered by a ghostly AI host named **Kiro**. Each session is a one-time ritual — Kiro generates personalized prompts, unique choices for every player, and unsettling group insights in real time using GPT-4o. Inspired by Cards Against Humanity and Jackbox, but built to feel genuinely *possessed*.

## ✨ Features

- **Ghostly AI Host** — Kiro narrates, judges, and adapts to your group's energy every round using GPT-4o
- **Personalized Hallucinations** — Each player receives uniquely generated choices tailored to them, not generic card draws
- **Real-Time Multiplayer** — Supabase powers live room state, voting, and synchronization across all players simultaneously
- **Ritual Flow** — Every 3 rounds Kiro evaluates the vibe; survive and the ritual deepens, falter and it prescribes a new theme
- **Atmospheric UI** — Framer Motion animations, eerie gradients, and ritualistic typography make every reveal feel haunted
- **Infinite Replayability** — Sessions are unrepeatable; themes range from *Cottagecore Rage* to *Deli-Sliced Trauma*

## 🚀 Getting Started

```bash
git clone https://github.com/kyisaiah47/deep-cut
cd deep-cut
npm install
cp .env.local.example .env.local  # add SUPABASE_URL, SUPABASE_ANON_KEY, OPENAI_API_KEY
npm run dev
```

Requires **Node 18+**. Open two browser windows at `http://localhost:3000` to experience the real-time multiplayer flow.
